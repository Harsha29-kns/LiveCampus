> **LiveCampus** is a real-time full-stack **College Event Management System** that enables seamless event organization, registration, and monitoring for Admins, Faculty, and Students. Powered by **JWT**, **Socket.IO**, **QR codes**, and modern web technologies.

---

## 🚀 Features

- ✅ Real-time updates via Socket.IO  
- ✅ Role-based dashboards (Admin, Faculty, Student)  
- ✅ Event creation, editing, and deletion  
- ✅ Event registration system for students  
- ✅ QR code attendance tracking  
- ✅ Email verification and forgot password  
- ✅ Media gallery with upload support  
- ✅ Responsive design with smooth UX

---

## 🧑‍💻 Tech Stack

**Frontend:**
- React.js
- Tailwind CSS
- Axios
- React Router DOM
- Socket.IO Client

**Backend:**
- Node.js
- Firebase
- JWT for authentication
- Nodemailer for emails
- Socket.IO for real-time updates
